# translate_text_v1

> Prompt 版本：v1　｜　用途：`POST /api/v1/collate` 的**译文子 Prompt**
> 设计依据：TECH_DESIGN §4「无独立翻译端点」——本文件不单独开接口，
> 而是在 `options.produceTranslation=true` 时由 `routers/collate.py` 取出
> `## FRAGMENT` 段，注入 `collate_v1.md` 的 `{{TRANSLATION_INSTRUCTION}}`，
> 与校勘结果同一次调用返回（F5 文白对照）。
> 注意：`## FRAGMENT` 段会被注入主 Prompt 后再统一渲染，段内不要使用 `{{...}}` 占位符。

## FRAGMENT

请在给出校勘建议的同时，为【待校勘文本】**全文**生成白话译文，写入 `translation` 字段：

- 忠实原文，不增不减：原文没有的意思不要补，原文有的意思不要漏。
- 通假字、借字按本字之义译出（如「说」通「悦」，译作「愉快」）。
- 人名、地名、书名、官职照录，必要时可就地加简短括注，不加脚注。
- 校勘建议不要写进译文：译文是「读通原文」的结果，不是「改正原文」的结果。
- 保持原文的语序层次与语气；不分段加小标题，不写导语或总结。
- 若原文因残缺或乱码而无法释读，用「□」对应，不得猜测补足，也不要省略不译。
- `translation` 字段只放译文正文，不要加引号、不要加「译文：」之类的标签。
