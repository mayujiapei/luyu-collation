# 试点问卷与任务脚本（SURVEY）

> 版本：v1.0（2026-10-09）。**招募试用同学有提前量，先于试点发放前定稿**（HANDOFF §6）。
> 本文件可直接复制到问卷平台（问卷星 / 飞书表单 / 纸质）使用。
> 判定口径与指标口径见 `docs/EVAL.md`；本文件只管"问什么、怎么发、怎么算"。

## 0. 合规与匿名（先读）

- 问卷**不收集**姓名、学校名称、学号、联系方式等可识别信息；被试以编号出现（`P01`、`P02`…）。
- 若因后续回访需要联系方式，单独用一张登记表收集，**只留在本地，不进任何参赛交付物**。
- 每份问卷开头放一句知情同意：「本问卷用于古籍智能校勘系统的课程/竞赛研究，
  全程匿名，答案只用于统计与产品改进。可随时退出。」
- 交付物截图前逐张自查：无校名、无 Logo、无导师与真实姓名（AGENTS.md 红线）。

## 1. 样本与发放

| 环节 | 人数 | 时点 | 对应 PRD 需求 |
|---|---|---|---|
| 需求调研（前测） | ≥10（文科师生） | 系统试用前 | PRD §2「必须补的调研」 |
| 试点满意度（后测） | ≥20（文科学生） | 用过系统后 | PRD §6 试点满意度 ≥80% |
| 效率对比计时 | 每组 ≥3 | 与后测同场 | PRD §6 效率提升 ≥3 倍 |

- 发放方式：优先线上表单（便于统计）；课堂现场可用纸质，事后人工录入。
- 回收后立即用编号归档，原始答卷转存 `docs/eval/survey/`（该目录不入交付物，只在本地留证）。

## 3. 任务脚本（同一场次内做，用于效率计时）

**准备**：两段**等价难度**的测试文本，各 300–500 字，均含已知错误（可用 `docs/eval/` 语料的
不同段落，但两组文本必须不同且难度匹配，避免记忆效应）。

**人工组（对照）**
1. 发放纸质/纯文本，说明「请找出其中的问题并写出校勘记」。
2. 从宣布开始到被试交卷计时 → `elapsedSec`。

**辅助组（实验）**
1. 打开系统，把文本**粘贴**进去（不用 OCR，避免把 OCR 误差混进效率指标）。
2. 说明「AI 会给建议，采纳与否由你决定；最后请导出校勘记」。
3. 从开始粘贴到**导出校勘记**计时 → `elapsedSec`。含阅读建议与决策时间。

**记录**（每人一行，存 `docs/eval/` CSV）：

```
participant,group,elapsedSec,correctionsFound,totalPoints,notes
P07,assisted,214,7,9,"
```

- `correctionsFound` 用 `docs/eval/` 的 ground truth 按 `EVAL.md §3.1` 的区间口径判命中。
- 事后按组算均值与**置信区间**（每组 ≥3 人，人少不要只报均值）。

## 4. 后测问卷（使用后 · 满意度）

**Q1** 建议的整体质量（1–5，5=很好）
**Q2** 每条建议给出的理由是否够你核查（1–5）
**Q3** 对通假字「只标注本字、不改动原文」的处理，你认同吗（1–5）
**Q4** 界面是否好用（双栏对照、竖排/横排、繁简切换）（1–5）
**Q5** 采纳 / 还原操作与「修改记录时间线」是否让你对结果更放心（1–5）
**Q6** 相比你原本的做法，这个系统是否更省时间（1–5）
**Q7** 你是否愿意在真实的作业或研究中使用它（1–5）
**Q8** 你有多大可能把它推荐给同学（0–10，NPS）

**Q9** 你遇到的最明显问题（多选）
- [ ] 漏报（该报的没报）　- [ ] 误报（报错了 / 报了不该改的）　- [ ] 理由不充分
- [ ] 太慢　- [ ] 繁简或竖排显示有问题　- [ ] 其他：______

**Q10** 开放题：最有用的一点是？最需要改进的一点是？

**Q11** 有没有出现过「它报对了、但你一开始怀疑」的情况？如果有，是哪里（这题用于核实
`EVAL.md §3.4` 的"额外正确"口径，即模型是否真的比标注人发现了更多合法校勘点）

## 5. 统计口径

| 项 | 口径 |
|---|---|
| 满意度正向 | 1–5 量表取 **4–5 分计正向**；正向比例 = 正向份数 / 有效份数 |
| 目标 | 正向比例 **≥80%**（PRD §6）；效率提升 **≥3 倍**（人工组均值 ÷ 辅助组均值） |
| 有效份数 | 完成全部量表题视为有效；开放题空缺不算无效 |
| 必报项 | 样本量、回收率、正向比例、效率倍数与置信区间、开放题原话摘录 |
| 缺失值 | 量表题缺失按"未作答"剔除该题，不用均值填补 |

**报告时不要只给均值**：人少（尤其是效率实验每组 ≥3 人）必须同时给区间，
否则"提升 3 倍"这种结论经不起追问。

## 6. 与评测集的衔接

- 问卷的 Q11 与 `EVAL.md §3.4` 是同一条线索的两端：问卷发现"模型报对了但标注人没标"的案例，
  复核后补进 ground truth 的 `inherent` 记录。
- 效率实验的 CSV 与评测集 CSV 分开放（`docs/eval/survey/` 与 `docs/eval/`），
  佐证材料里合并成一份 PDF 时注明数据来源与样本量。
