# 评测集与原始结果（`docs/eval/`）

> 口径见 `docs/EVAL.md`（**改口径先改那份**）。问卷回收数据与效率计时表放 `survey/` 子目录。
> 本目录的内容**不进参赛交付物**，只作本地留证与脚本复现；交付物里的图表从这里的 CSV 生成。

## 目录约定

```
docs/eval/
  README.md            本文件
  corpus/              评测语料：每段一个 .txt（clean 原文）
  groundtruth/         标注结果：case-XXX.json，格式见 EVAL.md §2.3
  runs/                每次评测的原始结果 CSV（列定义见 EVAL.md §5）
  scripts/             构建语料、注入错误、跑评测、算指标的脚本
  survey/              问卷与效率实验的回收数据（CSV），列定义见 SURVEY.md §3/§5
```

## 硬性要求

- **可复现**：`runs/` 里每个 CSV 必须能由 `scripts/` 从 `corpus/` + `groundtruth/` 重跑出来；
  同时记录数据集版本、Prompt 版本、模型名与供应商、日期（EVAL.md §8）。
- **标注自检**：每条 GT 都要通过 `text[start:end] == original` 的脚本校验；
  标注人自检后再由第二人抽 20% 复核（EVAL.md §9）。
- **不落用户数据**：这里只放公共版权语料与本人构造的标注；真实被试的可识别信息一律不入库
  （回访用的联系方式登记表另存本地，见 SURVEY.md §0）。
- **语料来源登记**：每段语料在 `corpus/` 的伴生元数据里注明书名、篇名、版本出处，
  供论文附录与合规说明使用（TECH_DESIGN §9）。
