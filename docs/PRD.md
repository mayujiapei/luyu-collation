# 需求文档（PRD）— 古籍智能校勘系统

> 参赛赛道：2026 第八届全球校园人工智能算法精英大赛·算法创新赛 · **赛题 5：AI+学科交叉**
> 版本：v1.0（2026-10-02）

## 1. 定位与学科界定

- **学科领域**：中国古典文献学 / 汉语言文学（文科）。
- **赋能的核心环节**（赛题要求至少一个，我们覆盖三个）：
  1. **科研**：古籍数字化整理中的校勘环节；
  2. **教学**：古籍阅读类课程的课堂辅助；
  3. **自主学习**：文白对照与划词释义。
- **一句话定位**：大模型驱动的古籍"AI 建议 + 人工决策 + 全程留痕"人机协同校勘系统，输出符合文献学规范的校勘记。

## 2. 痛点（需求分析素材，对应评分项"需求分析 15 分"）

| 痛点 | 现状 | 佐证方式 |
|---|---|---|
| OCR 错字多 | 古籍 OCR 生僻字、形近字误识率高，错字直接进入下游 | 对比实验：OCR 原文 vs 权威整理本 |
| 人工校勘慢 | 逐字比对耗时，一名研究者日均处理量有限 | 试点问卷 + 计时实验 |
| 校勘记编写繁 | 校勘记有固定体例，手工编写重复劳动大 | 访谈中文系师生 |
| 通用工具不适配 | 通用文本校对工具不懂通假、异文、竖排繁体 | 竞品对比表 |

**必须补的调研**：≥10 份文科师生访谈/问卷（试用前一次、试用后一次），形成《学科需求分析报告》素材。

## 3. 用户与场景

- **主要用户**：古籍整理研究者、文科研究生、中学/大学语文（古文）教师、古籍爱好者。
- **核心场景**：
  - S1 科研校勘：粘贴/上传 OCR 文本 → 系统给出校勘建议（类型+理由+置信度）→ 人工采纳/还原 → 导出规范校勘记。
  - S2 课堂/自学：文白对照阅读，划词查看释义，繁简/竖横排切换。

## 4. 功能需求

| 编号 | 功能 | 优先级 | 验收标准 |
|---|---|---|---|
| F1 | 文本粘贴/文件上传入口 | P0 | 支持 .txt 粘贴直传；内容真实传入校勘页（经 Pinia，不落硬编码） |
| F2 | 大模型智能校勘 | P0 | 识别讹字、衍文、脱文、通假、异文五类；每条含原文片段、建议、理由、置信度、类型；JSON schema 校验 |
| F3 | 校勘建议人工决策 | P0 | 逐条采纳/还原 + 全部采纳/一键还原；操作实时写入修改时间线（已有 UI，接真实数据） |
| F4 | 校勘记导出 | P0 | 按文献学体例导出（示例："「曰」，底本误作「日」，形近而讹，据通行本改。"）；导出 .txt |
| F5 | 文白对照 | P0 | 大模型生成白话译文，与原文同屏展示（已有 UI 位置） |
| F6 | 划词释义 | P1 | 长按划词调后端释义接口（替换现有 mock 字典） |
| F7 | 图片 OCR 识别 | P1 | 上传古籍图片 → OCR API → 文本进入 F2 流程；失败可降级为手动粘贴 |
| F8 | 繁简/竖横排展示 | 已完成 | opencc-js 已实现，保持 |

**明确不做**（范围切割，防止贪多误期）：用户系统/多人协作、版本管理、数据库持久化、移动端、自研 OCR/自训模型、支付与商业化。

## 5. 非功能需求

- 单次校勘文本 ≤5000 字，响应 ≤30s（超时友好提示）。
- 大模型/OCR 密钥只在服务端，前端零密钥。
- 后端无状态；不存储用户文本（隐私与合规说明素材）。
- 主链路在断网/API 失效时有明确降级提示（但演示环境必须保证可用）。

## 6. 效果验证指标（对应评分项"应用效果 20 分"，必须落地）

| 指标 | 目标 | 测量方法 |
|---|---|---|
| 校勘检出 F1 | ≥0.8（小样本） | 10 段古籍（有权威整理本作 ground truth），人工注入/天然 OCR 错误，算 precision/recall |
| 校正准确率 | ≥85% | 检出的错误中建议正确的比例 |
| 效率提升 | ≥3 倍 | 同一段文本：纯人工校勘计时 vs AI 辅助校勘计时（各 ≥3 人参与） |
| 试点满意度 | ≥80% 正向 | ≥20 名文科学生试用问卷 |

## 7. 实施顺序（阶段一）

按依赖关系排序，不设日历日期：

1. F1+F2+F3 端到端真实链路（粘贴路径）——最高优先级，其余一切让路；
2. F4 校勘记导出 + F5 译文真实化 + 加载/错误态；
3. F6 划词释义 + F7 OCR（可选闸门：时间不够则砍 F7，粘贴路径足够）；
4. 对比实验 + 试点问卷，产出数据图表；
5. 技术方案 PDF、演示视频（3–5min MP4 ≤300MB）、答辩 PPT。

外部赛程节点（以当年官方通知为准）：校赛提交、省赛报名材料定稿。
